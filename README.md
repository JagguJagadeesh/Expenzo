Expenzo — Family Expense Tracker

A clean, private, multi-user family expense tracking application.
Built with Next.js (web) and Express + TypeScript (api).

Expenzo keeps household spending transparent and organized. Each family member gets their own account, can log expenses, view insights, and track monthly totals. No drama, no confusion—just simple money clarity for the whole family.

🚀 Tech Stack
Frontend (web)

Next.js 15 (TypeScript)

React

TailwindCSS

Shadcn/UI (optional)

Chart.js / Recharts (for graphs)

Axios

Backend (api)

Node.js

Express (TypeScript)

Prisma / MongoDB or PostgreSQL (based on what you choose)

Zod (optional for validation)

JWT or Clerk/NextAuth (authentication)
